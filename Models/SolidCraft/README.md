# SolidCraft Models
SolidCraft is under very rapid open source development. As such, the models in this folder may/may not work in a current version. Use at you own risk.

## Current Conversion Activity
All of the original Solid Edge english unit solid models are being converted to metric unit SolidCraft models, as metric units are native to 3D printing slicers. 

SolidCraft is open source, mimicking the Autodesk Fusion software functionality and supporting the Model-Context-Protocol (MCP) AI interface. A long term objective of DahlStar is to develop an AI-based process and software that reads a solid model definition of an antenna assembly (including it's environmental surroundings), converts it to input decks for analysis software (such as NEC2), initiates and runs the analysis software, and provides a means of viewing and interpreting the results. 

In the conversion process, extensive definitions of parameters are being made and used to facilitate rapid modifications throughout the assembly. It is envisioned that optimization could be facilitated by AI using the aforementioned process and tools.

## Status
2026/11/07: The coil form segments and the coil form support tube have been modelled, with the exception of the coil grooves. SoliCraft is not yet capable of modelling that, and I have reported it as an issue to the development team. They are currently focused on incorporating a new backend math model into the product. It is unknown how that will perform in regards to this once they make it public.
